# 🛒 Regina Mart

## Online Grocery Shopping Management System using C++

Regina Mart is a console-based grocery shopping management system developed using **C++**.

The project allows users to register, log in, view available products, search for products, add products to a shopping cart, view the cart, and complete checkout.

---

## 📌 Project Features

- 👤 User Registration
- 🔐 User Login
- 🛍️ View Products
- 🔎 Search Products
- 🛒 Add Products to Cart
- ➕ Select Product Quantity
- 💰 Calculate Total Price
- 💳 Checkout
- 👤 View User Profile
- 🚪 Logout

---

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Compiler:** G++
- **IDE:** Visual Studio Code
- **File Handling:** C++ File Streams
- **Data Storage:** Text File (`users.txt`)
